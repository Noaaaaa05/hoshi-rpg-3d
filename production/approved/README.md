# Rights-cleared production bundles only

Do not put the user's uploaded ZIP, unknown-license images, watermarked sheets, or unreviewed crops here.

The optional paid workflow accepts a bundle only after PNG hashes, quality approval, license evidence, derivative permission, publication permission, and a separately authorized operation/count/credit ceiling have been recorded. Nothing is submitted by default. See [the asset pipeline guide](../../docs/BULK_ASSET_PIPELINE.md).
