## 続きから進める

1. [運用手順](RPG_AUTOMATION.md) を読み、`assets/rpg/catalog.json` の `mina` と `watchpost-round` で実運用例の登録状況を確認する。未登録なら [依頼例](requests/watchpost.json) をカタログに適用する。
2. `Game checks` とPagesを確認する。実運用例の合格条件は、ミナとの会話、見張り台への訪問、報酬、三連撃・同行の解放、セーブからの復帰。
3. 次の依頼では同じカタログを使う。新しい仕組みが必要ならコードPRで追加し、ゲームデータの追加PRと切り分ける。無料の調査や実装は、有料の承認待ちでも進める。

## 見た目の方針と置き換え対象

所有者の指示（2026-11-17）：3D RPGとして作る。ドット絵風の見た目や、箱を組み合わせた四角い見た目にはしない。新しいキャラクター・敵・武器・建物・小物は、造形とテクスチャのある3Dモデル（GLB）で追加する。

いまの表示は次のとおり。どれも仮のもので、3Dモデルへ置き換える。

| 対象 | いまの表示 | 場所 |
| --- | --- | --- |
| 主人公 | Meshy製の66ボーンGLB。画像とマテリアルがなく単色 | `assets/models/hero_animated.glb` |
| ミナなどカタログのNPC | 箱の胴体と球の頭を組み合わせた `scout` プリセット | `js/rpg-visuals.js` |
| 見張り台の小屋と灯り | 箱と四角錐の `cottage`、箱と球の `beacon` プリセット | `js/rpg-visuals.js` |
| 集落の家・屋台・NPC3人 | 箱、円柱、円錐、球 | `js/village.js` |
| スライムとゴブリン | 球と箱のインスタンス | `js/monsters.js` |
| 森の木・岩・石門 | 円錐、多面体、箱 | `js/world.js` |

置き換えにはMeshyの有料生成が必要になる。対象ごとに現行の料金で見積もりを出し、所有者の承認を得てから実行する。
