## 将来アニメーションを追加する

リグとクリップを含むGLBをアップロードし、`player.url` をそのファイルに変更して、`animations` の6項目を実際のクリップ名に合わせます。

```json
"animations": {
  "idle": "Idle",
  "walk": "Walk",
  "run": "Run",
  "attack": "Attack",
  "jump": "Jump",
  "dodge": "Dodge"
}
```

Idle / Walk / Runはループ、Attack / Jump / Dodgeは一度ずつ再生します。連続攻撃ではAttackを再開し、ポーズ画面ではアニメーションも停止します。クリップがなければ無理な変形は行いません。移動はゲーム側が管理するため、移動系クリップはその場で再生する in-place 形式を推奨します。

軽量版の再生成はPCで次のコマンドを実行できます。スマホで遊ぶ・GitHub Pagesで公開する際には不要です。

```sh
blender --background --python scripts/optimize-hero.py
```

この補助スクリプトは今回の静的モデル向けです。リグ・アニメーション・モーフのあるモデルは処理を停止し、それらを削除して書き出しません。
